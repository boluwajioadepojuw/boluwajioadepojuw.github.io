# projects

Everything below is on GitHub, MIT-licensed, with CI running on every push.

SOCAtelier

The core lab. Elastic, osTicket and a self-built triage console (FastAPI + React + D3) in Docker; Suricata on the gateway. Atomic Red Team runs validated the rules; four Linux cases were captured live from the lab host itself.

ElasticSuricataFastAPIReactSysmonDocker
96 detection rules · 18 Sigma rules · 90 behavioral profiles · 14 investigations · 22 tests
repository →

SplunkHarbor

Splunk in Docker with a PowerShell script that installs the Universal Forwarder on a Windows endpoint. Five SPL detections — brute force, encoded PowerShell, scheduled tasks, lateral movement, persistence — plus an alert-to-write-up walkthrough.

SplunkSPLSysmonPowerShellDocker
5 SPL detections · triage walkthrough · live dashboards
repository →

SigScope

Detection as code. A Python CLI that maps Sigma rules onto MITRE ATT&CK and renders HTML, CSV, a coverage badge and a gap workbook — every uncovered technique listed with its tactic and a next action. CI fails the build when coverage drops.

PythonSigmaATT&CKCI gate
24 tests · coverage gate in CI · ATT&CK Navigator export
repository →

IocVerdict

Threat-intel console: feed it an IP, domain, URL or hash and it asks six free sources, scores the indicator 0-100 and maps it to MITRE. The verdict lands in the investigation reports.

PythonThreat intelIOC
6 free sources · 0-100 scoring · MITRE mapping
repository →

DomainSieve

Phishing-domain sieve. Downloads the Newly Registered Domains feed, scores for brand impersonation and turns suspicious domains into Suricata rules that block them at the gateway.

PythonSuricataNRD feed
daily NRD feed · Suricata rule generation
repository →

ArpSieve

Network layer of the lab. Watches ARP traffic live and in pcaps, detects poisoning, and alerts — with sample captures committed as test fixtures.

PythonARPpcap
live and pcap detection · sample captures as fixtures
repository →

# timeline

Two years of building, one account. Every commit keeps its original date.

Nov 2024

SOCAtelier begins

First commit of the lab that became the system. Elastic and detection rules take shape.

2025

Study and groundwork

Linux, networking and Elastic fundamentals; the lab kept running. No public commits until the account went live.

Mar 2026

SplunkHarbor

Second SIEM. Universal Forwarder deployment script, five SPL detections, triage walkthrough.

Apr 2026

SigScope

Sigma rules get a coverage gate: CI fails when ATT&CK coverage drops.

Jun 2026

Atomic Red Team stress run

330 atomics, 708 behaviors executed against the lab; datasets and findings documented.

Sep 2026

Lynx console + live Linux captures

The FastAPI + React triage console goes live; four investigations captured from the real lab host, real processes, real timestamps.

Oct 2026

Published

The account goes public: six repositories, CI on every push, this site. The oldest commit is from 10 November 2024.

This GitHub account was created in October 2026. Nothing is backdated: every commit above carries its original timestamp, and SOCAtelier's history is verifiable back to November 2024.
