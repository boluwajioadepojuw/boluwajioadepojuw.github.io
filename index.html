02 — projects

# projects

Everything below is on GitHub, MIT-licensed, CI runs on every push, and each screenshot was taken during a live run of the tool.

SOCAtelier

The core lab. Elastic and osTicket in Docker, Suricata on the gateway, and Lynx — a triage console I built (FastAPI + React + D3) with case queue, process trees, cross-layer correlation and a hunt workbench. Four Linux cases were captured live from the lab host itself.

ElasticSuricataFastAPIReactSysmonDocker
96 detection rules · 18 Sigma rules · 90 behavioral profiles · 14 investigations · 22 tests
repository →

SplunkHarbor

Splunk in Docker with a PowerShell script that installs the Universal Forwarder on a Windows endpoint. Five SPL detections — brute force, encoded PowerShell, scheduled tasks, lateral movement, persistence — shipped as saved searches with dashboards and an alert-to-write-up walkthrough.

SplunkSPLSysmonPowerShellDocker
5 SPL detections · 3 live dashboards · triage walkthrough
repository →

SigScope

Detection as code. A Python CLI that maps Sigma rules onto MITRE ATT&CK and renders HTML, CSV, a coverage badge and a gap workbook — each uncovered technique listed with its tactic and a next action. CI fails the build when coverage drops.

PythonSigmaATT&CKCI gate
24 tests · coverage gate in CI · Navigator export
repository →

IocVerdict

Threat-intel console: feed it an IP, domain, URL or hash and it asks seven free sources, folds the answers into one 0-100 score and maps it onto MITRE. The run in the screenshot scored a live Emotet/QakBot C2 IP and a URLhaus-listed URL.

PythonThreat intelIOC
7 free sources · 0-100 scoring · MITRE mapping
repository →

DomainSieve

Phishing-domain sieve. Downloads the Newly Registered Domains feed, keeps the domains that impersonate watched brands, and turns them into Suricata rules for the gateway. The captured run pulled today's feed and wrote 24 rules from 8 suspicious domains.

PythonSuricataNRD feed
daily NRD feed · live run: 8 hits, 24 rules
repository →

ArpSieve

Network layer of the lab. Watches ARP traffic live and in pcaps, detects poisoning, and alerts — the captured run shows a benign capture passing clean and a poisoned capture raising the spoofing alert.

PythonARPpcap
live and pcap detection · sample captures as fixtures
repository →
